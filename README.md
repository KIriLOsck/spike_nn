# Конструктор спайковой нейросети

### Статус: 🚧 В активной разработке

Данный код представляет реализацию конструктора спайковых нефронных сетей, имитирующих процессы в биологическом мозге. Код позволяет создавать, компилировать, обучать и маштабировать нейропластичные модели.

### ⚠️ Важное примечание

Этот проект находится в стадии активной разработки. Архитектура, API и функциональность могут существенно меняться. Код не является стабильным и не предназначен для production-использования.

### 🚀 Начало работы

```py
from nn import SpikeNeuralNetwork

nn = SpikeNeuralNetwork(
        100,        # общее колличество нейронов
        30,         # сколько нейронов с начала будут считаться входными
        3           # сколько нейронов с конца будут считаться выходными
    )
```

#### Изменение параметров

```py
nn._ACTIVATION_RADIUS = 10       # предел расстояния для связи нейронов
nn._ACTIVATION_DEVISOR = 5       # обратно пропорционален вероятности активации нейрона
nn._BASE_STRENGTH = 0.01         # вес новой связи по умолчанию
nn._BASE_OLD = 1                 # возраст новой связи по умолчанию
nn._REFRACT_PERIOD = 0           # рефрактный период в итерациях. 0 отключает рассчёт


# влияет на шум и порог активации. Чем ниже тем больше шум, меньше порог. При значнии 1 порог будет 0.5
nn.SEROTONIN = 1.0

# < 1 связи удаляются; > 1 усиливаются. Стремится к одному, регулируется в зависитости от ошибки.
nn.DOPHAMIN = 1.0

nn.learning_rate = 0.01          # как быстро дофамин будет приравниваться к 1
```

#### Методы класса SpikeNeuralNetwork

`get_output() -> list` - Возвращает сырые данные из нейросети или с применённой активацией.
- `reLU` если `True` возвращает список {1, 0} в зависимости активируется ли нейрон на следующей итерации.

`iteration() -> list` - Производит один шаг в нейросети с поддержкой нейропластичности и возвращает результат работы. Удалает старые связи; Подставляет входные значения; Создаёт связи; Расчитывает порог; Проводит спайки.
- `iteration` номер текущей итерации.
- `interval` максимальный временной интервал в итерациях при котором 2 нейрона могут быть связанны.
- `inputs` список значений которые будут подставлены во входные нейроны.
- `reLU` если `True` возвращает список {1, 0} в зависимости активируется ли нейрон на следующей итерации.

`set_inputs()` - Применяет лист входных значений, к потенциалу входных нейронов.
- `inputs` список значений которые будут подставлены во входные нейроны.

`test_result() -> int, list` проводит 100 итераций на выбранных данных и на основе колличества спайков выходных нейронов вычисляет точность.
- `batch` выбранные данные формата `[ [входные данные], [ожидаемые данные] ]`.
- `interval` максимальный временной интервал в итерациях при котором 2 нейрона могут быть связанны.
